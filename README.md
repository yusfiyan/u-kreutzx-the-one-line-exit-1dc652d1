# The One-Line Exit

One funny resignation letter, exactly one line long:

> Dear Zoo, I resign as your penguin keeper — the penguins have unionised, and frankly, their demands are reasonable.

Run: `MAKEFUN_OUTPUT_DIR=<dir> node main.ts` — writes `entry.txt` (115 characters) to that directory only.
